# Авиадиспетчер — симулятор ATC

Браузерная игра: ты авиадиспетчер, заводишь самолёты на посадку на полосу RWY 09.
Вся игра — один HTML-файл на canvas, без зависимостей и сборки.

- 📱 [Играть на телефоне (версия под iPhone)](mobile.html)
- 🖥️ [Играть на компьютере](index.html)

## Как играть
- Тап/клик по самолёту — выбрать; тап/клик по пустому радару — вектор на точку
- `W`/`S` или кнопки ▲▼ — высота ±1000 футов
- `A`/`D` или кнопки — скорость ±10 узлов
- `L` или кнопка «ПОСАДКА» — допуск к посадке
- Условия посадки: на оси полосы, курс на восток, высота ≤ 3500 футов, скорость ≤ 210 узлов
- Столкновение бортов — конец игры; пропуск — минус жизнь (всего 3)
- `P` — пауза, `R` — заново, `M` — звук
